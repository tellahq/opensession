# Session pickup

Resume prior work from the real trail without redoing it.

1. Identify the exact prior session, branch, PR, or handoff. Use policy-gated Open Session session/history tools and verify the explicit creator. Never infer ownership from a title or scan transcript files or databases.
2. Read recent state first, then the relevant transcript windows around decisions, errors, filenames, or symbols. Treat a summary as a hint until the real transcript or repository confirms it.
3. Inspect the current checkout, branch, worktree, diff, staged files, commits, PR state, pending questions, and errors. Preserve partial and unrelated work.
4. Reconstruct the goal, accepted decisions, completed units, current blocker, exact verification already run, and next safe action.
5. Falsify the handoff against disk and live state. A stale or mistaken handoff never overrides what is actually present.
6. Continue from the first unproven unit. Do not rerun expensive work unless its evidence is missing or invalidated.
7. Leave a compact updated checkpoint when the work pauses again.

Report the recovered state, discrepancies, next action, and evidence links.
